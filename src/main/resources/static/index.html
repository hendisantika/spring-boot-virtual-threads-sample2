Virtual threads (Java 21)

  • 🪶1,000 virtual threads, all start now
  • ⚙️A few carrier (OS) threads do the work
  • ⬇️DB wait → virtual thread unmounts, carrier is free
  • ⬆️Data back → it remounts and continues

1. More users, not speed

More requests at once. One request is not faster.

2. Don't pool them

One per task: Executors.newVirtualThreadPerTaskExecutor()

3. Watch synchronized

Avoid long waits inside it. Use ReentrantLock.

Spring Boot 3.2+: spring.threads.virtual.enabled=true
